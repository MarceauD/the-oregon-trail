# Mythic GME - Event Focus Table
*Table extraite de Mythic GME 2.pdf (Pages 14 & 49)*

1-7: Remote event (Événement distant / Hors-champ)
8-28: NPC action (Action d'un PNJ)
29-35: Introduce a new NPC (Introduction d'un nouveau PNJ)
36-45: Move toward a thread (Avancer vers un Thread)
46-52: Move away from a thread (S'éloigner d'un Thread)
53-55: Close a thread (Clôturer un Thread)
56-67: PC negative (Négatif pour un PJ)
68-75: PC positive (Positif pour un PJ)
76-83: Ambiguous event (Événement ambigu / Atmosphérique)
84-92: NPC negative (Négatif pour un PNJ)
93-100: NPC positive (Positif pour un PNJ)
